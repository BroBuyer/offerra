# thalora

Teal handelsplattform-mal for Offerra, visuell klone av landingen (hjem, undersider, CSS, bilder, chat).

- **Kildespråk:** engelsk i roten (`SITE_LANG=en`); norsk i `langs/no/`; Spanish in `langs/es/`; Norwegian in `langs/no/`; Malay in `langs/ms/`
- **Look:** universal teal (`#0d7377`), Inter + Unbounded, Tailwind build from the sample

Lead forms use the sample card UI (`apx-lead`) but Offerra fields (`fname`, `lname`, `email`, `fullphone`) and `integration/send.php`.
