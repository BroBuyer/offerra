# lumen

Light “wealth studio” template for Offerra — premium investing feel with AI guidance.

- **Langs:** English root (`SITE_LANG=en`) + 18 localized packs under `langs/` (`de`, `es`, `fr`, `it`, `pl`, `nl`, `pt`, `cs`, `sk`, `hu`, `ro`, `hr`, `tr`, `sv`, `no`, `da`, `fi`, `el`)
- **i18n:** copy packs in `scripts/lumen-i18n/*.json` (134 keys); build with `node scripts/build-lumen-langs.mjs`
- **Look:** ink navy + paper + electric teal, Fraunces display + Outfit UI
- **Theme:** simple AI investing platform (not a dark terminal)
- **Logic:** same `integration/` stack as `noctra` / `default` (form token, LeadProcessor, Keitaro, mirrors/CWV)
