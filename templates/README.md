# Шаблони лендів

Кожна **підпапка** тут — окремий шаблон у випадаючому меню генератора.

```
templates/
  default/          ← приклад: базовий SEO-ленд
    index.php
    includes/
    langs/          ← опційно: en/, it/, tr/ …
      en/
      it/
```

- **Мови** для шаблону: з `langs/*` + з уже згенерованих оферів у `offers/` (за `manifest.json`).
- Новий шаблон — скопіюй папку `default`, перейменуй, поклади сюди.
